LocalSLM WebAssembly Runner

Aplikasi ini siap menjalankan inferensi asli dari file model .gguf milikmu langsung di memori browser via WebAssembly (tanpa server cloud!).

Cara Menggunakan:

  1. Pilih file GGUF yang tersimpan di memori HP.
  2. Klik tombol ⚡ Muat Model ke WASM Engine.
  3. Ketik pesan dan ajukan pertanyaan asli!

Arsitektur APK Android Native (llama.cpp C++)

Versi ini ditujukan untuk dijalankan langsung di browser Android. Tidak perlu APK, Python, terminal, atau server lokal. Runtime Wllama JS dan WASM dapat dipilih secara manual dari penyimpanan HP.

1. Library Backend C++ (llama.cpp)

Compile llama.cpp menjadi library shared libllama.so dengan Android NDK (ARM64-v8a + NEON/DotProd).

2. JNI Interop (Kotlin / Java)

Gunakan Java Native Interface (JNI) untuk memanggil fungsi llama_decode() dan llama_tokenize() dari Kotlin.

3. Memory Mapping (mmap)

File GGUF dibaca menggunakan mmap() langsung dari storage internal. Untuk model 0.8B Q8, konsumsi memori hanya sekitar $800 \text{ MB} \times 1.2 \approx 960 \text{ MB RAM}$.
